## Виклад

### 1. Відступи (6 хв)

У більшості мов блок коду беруть у фігурні дужки. У Python блок задається
**відступом**.

```python
age = 18
if age >= 18:
    print("Ви повнолітній")      # це всередині if — 4 пробіли
print("Ця стрічка виконається завжди")   # це вже поза if
```

Три правила:

1. Після `if`, `else`, `for`, `while` **обов'язково двокрапка**.
2. Наступний рядок — **із відступом**. Стандарт: 4 пробіли (VS Code ставить сам,
   якщо натиснути `Tab`).
3. **Не змішуй табуляцію й пробіли** в одному файлі. Візуально однаково, а
   Python видасть `TabError`.

🖥 Покажи на проекторі, як зміна відступу змінює **сенс** програми:

```python
for i in range(3):
    print("всередині", i)
print("зовні")
```

а потім зсунь останній `print` усередину — і виведення зміниться. Клас мусить
побачити, що відступ — це не краса, а логіка.

### 2. Галуження (12 хв)

```python
age = 18
if age >= 18:
    print("Ви повнолітній.")
```

```python
age = 16
if age >= 18:
    print("Ви повнолітній.")
else:
    print("Ви неповнолітній.")
```

```python
score = 85
if score >= 90:
    print("Оцінка: 12")
elif score >= 80:
    print("Оцінка: 10")
elif score >= 70:
    print("Оцінка: 8")
else:
    print("Оцінка: нижче 8")
```

⚠ **Ключова властивість `elif`, яку варто розібрати уважно:** перевірки йдуть
**по черзі, і виконується лише перша, що спрацювала**. Тому порядок умов має
значення.

Питання класу: **що буде, якщо в прикладі вище поміняти умови місцями й
поставити `score >= 70` першою?** Усі, у кого 85, отримають «8» — бо перша
умова вже істинна, і до решти справа не дійде. Це найпоширеніша логічна помилка
в задачах з оцінками.

**Оператори порівняння** — виписати на дошці:

| Оператор | Значення |
|---|---|
| `==` | дорівнює |
| `!=` | не дорівнює |
| `>` `<` `>=` `<=` | порівняння |
| `and` | і |
| `or` | або |
| `not` | не |
| `in` | входить |

⚠⚠ **`=` і `==` — різні речі.** `=` присвоює, `==` порівнює. Це помилка номер
один у всіх, хто починає.

Зв'яжи з SQL: там теж були `AND`, `OR`, `NOT` (день 7), і там теж `AND`
виконувався раніше за `OR`. У Python **так само**, і дужки так само врятують.

### 3. Цикл while (10 хв)

Повторює, **поки умова істинна**.

```python
count = 0
while count < 5:
    print("Count:", count)
    count += 1
```

`count += 1` — те саме, що `count = count + 1`.

⚠⚠ **Головна небезпека — нескінченний цикл.** Якщо забути `count += 1`, умова
залишиться істинною назавжди.

🖥 Покажи це навмисно на проекторі й покажи, як зупиняти: **`Ctrl+C` у
терміналі**. Клас мусить знати цю комбінацію ще до того, як зависне вперше.

Три речі, які потрібні `while`, — варто дати як чекліст:

1. змінна **до** циклу (`count = 0`)
2. умова, яка колись стане хибною (`count < 5`)
3. **зміна цієї змінної всередині** (`count += 1`)

Забув третє — програма зависла.

Особливість Python, яку варто згадати: у циклу може бути `else`, який
виконується після нормального завершення:

```python
while count < 5:
    print(count)
    count += 1
else:
    print("Цикл завершено")
```

⚠ Це рідкість, і в інших мовах такого немає. Достатньо знати, що воно існує.

### 4. Цикл for (10 хв, головна частина)

`for` перебирає **послідовність**, і саме він у Python використовується
найчастіше.

```python
for i in range(5):
    print("Number:", i)          # 0, 1, 2, 3, 4
```

⚠ `range(5)` дає числа **від 0 до 4**, п'ять штук, останнє **не включається**.
Це той самий принцип «з нуля», що й індекси рядків (день 19).

Три форми `range`:

```python
range(5)          # 0 1 2 3 4
range(2, 6)       # 2 3 4 5
range(0, 10, 2)   # 0 2 4 6 8 — із кроком
range(5, 0, -1)   # 5 4 3 2 1 — назад
```

Перебрати можна не лише числа:

```python
for x in "banana":
    print(x)                    # b a n a n a — по літерах

for fruit in ["яблуко", "банан", "черешня"]:
    print(fruit)
```

**Коли `while`, а коли `for`** — правило, яке варто дати під запис:

| Ситуація | Цикл |
|---|---|
| Знаю, **скільки разів** повторити | `for` |
| Перебираю готову послідовність | `for` |
| Повторюю, **поки щось не станеться** (правильне введення, вгадане число) | `while` |

### 5. break, continue, вкладені цикли (5 хв)

```python
for i in range(10):
    if i == 5:
        break            # вийти з циклу зовсім
    print(i)             # 0 1 2 3 4
```

```python
for i in range(5):
    if i == 3:
        continue         # пропустити цю ітерацію
    print(i)             # 0 1 2 4
```

**Вкладений цикл:**

```python
for i in range(3):
    for j in range(2):
        print(f"i: {i}, j: {j}")
```

⚠ Тут з'являється `f-рядок` — `f"текст {змінна}"`. Скажи одним реченням, що це
зручний спосіб вставити значення в текст; детально буде на дні 26.

Головне про вкладені цикли: **внутрішній повністю прокручується на кожен крок
зовнішнього.** 3 × 2 = 6 рядків виведення. Порахуй це вголос із класом — інакше
на практиці таблиця множення не складеться.

## ⚠ Що піде не так

| Симптом | Причина | Що робити |
|---|---|---|
| `IndentationError: expected an indented block` | немає відступу після двокрапки | 4 пробіли |
| `TabError: inconsistent use of tabs and spaces` | змішали `Tab` і пробіли | у VS Code: `Convert Indentation to Spaces` |
| `SyntaxError` на рядку з `if` | забуто двокрапку | `:` у кінці |
| Програма зависла | нескінченний `while` | `Ctrl+C`; перевірити чекліст із трьох пунктів |
| Умова з оцінками працює неправильно | порядок `elif` | розділ 2, питання про порядок |
| `SyntaxError: invalid syntax` на `if x = 5` | `=` замість `==` | одне присвоює, друге порівнює |
| `range(5)` не дає 5 | останнє не включається | так і має бути |

**Крок 7. Таблиця множення** — вкладений цикл, головне завдання практики:


**Гра «вгадай число»** (крок 7.3) — найкраще підсумкове завдання блоку:
потрібні `while`, `if…elif…else`, `int(input())` і `break`. Хто зробив її сам —
засвоїв день.

```python
import random
secret = random.randint(1, 100)
attempts = 0
while True:
    guess = int(input("Твоє число: "))
    attempts += 1
    if guess < secret:
        print("Більше")
    elif guess > secret:
        print("Менше")
    else:
        print(f"Вгадав за {attempts} спроб!")
        break
```

⚠ `import random` — перше знайомство з модулями. Скажи одним реченням, що
детально це буде на дні 28.
