## Виклад

### 1. Чотири структури поруч (4 хв)

Почни з таблиці — учні перепишуть її й будуть до неї повертатись:

| | Список `[]` | Кортеж `()` | Множина `{}` | Словник `{:}` |
|---|---|---|---|---|
| Порядок | є | є | **немає** | є (з Python 3.7) |
| Змінюваний | так | **ні** | так | так |
| Дублікати | можна | можна | **не можна** | ключі унікальні |
| Доступ | за індексом | за індексом | лише перебором | **за ключем** |

```python
my_list  = [1, 2, 3, 3]
my_tuple = (1, 2, 3, "яблуко")
my_set   = {1, 2, 3, 3}                  # → {1, 2, 3}
my_dict  = {"name": "Аліса", "age": 15}
```

⚠ Зверни увагу: фігурні дужки використовуються і для множини, і для словника.
Різниця в тому, чи є двокрапка. І одна пастка: `{}` — це **порожній словник**,
не множина. Порожня множина — `set()`.

### 2. Кортежі (10 хв)

```python
my_tuple = (1, 2, 3, "яблуко", "банан")
```

Працює так само, як список — **на читання**:

```python
print(my_tuple[0])       # 1
print(my_tuple[-1])      # банан
print(my_tuple[2:4])     # (3, 'яблуко') — зріз
print(len(my_tuple))     # 5
print("яблуко" in my_tuple)
print(my_tuple.count("яблуко"))
print(my_tuple.index(3))    # 2
```

А на зміну — **ні**:

```python
my_tuple[0] = 99      # ⚠ TypeError: 'tuple' object does not support item assignment
```

🖥 Покажи цю помилку на проекторі.

Що можна: **склеїти** два кортежі, створивши третій:

```python
new_tuple = my_tuple + (4, 5, 6)
```

**Розпакування** — приємна річ, яку варто показати:

```python
fruits = ("яблуко", "банан", "черешня")
green, yellow, red = fruits
print(green)     # яблуко
```

Питання класу: **навіщо взагалі структура, яку не можна змінити?** Три
відповіді:

1. **Захист від помилки.** Координати точки, дата, розмір екрана, налаштування —
   те, що не мусить змінитись випадково. Якщо хтось спробує — програма впаде
   одразу, а не через тиждень із дивними даними.
2. **Кортеж може бути ключем словника, а список — ні.** Це знадобиться в
   розділі 4.
3. Він трохи швидший і займає менше пам'яті.

Формула для запису: **список — для того, що змінюється; кортеж — для того, що
не мусить.**

### 3. Множини (12 хв)

```python
my_set = {1, 2, 3, "яблуко"}
```

Головна властивість — **унікальність**:

```python
numbers = [1, 2, 2, 3, 3, 3, 4]
unique = set(numbers)          # {1, 2, 3, 4}
back_to_list = list(unique)    # знову список, але вже без дублікатів
```

⚠ Зв'яжи з SQL: це рівно те саме, що `SELECT DISTINCT` на дні 7. Хай хтось із
класу це назве сам.

Додати й видалити:

```python
my_set.add("банан")
my_set.remove("яблуко")     # ⚠ KeyError, якщо елемента немає
my_set.discard("апельсин")  # тихо, без помилки
my_set.clear()
```

**Математичні операції** — те, для чого множини й придумали:

```python
set1 = {1, 2, 3}
set2 = {3, 4, 5}

print(set1 | set2)    # {1,2,3,4,5}  об'єднання (union)
print(set1 & set2)    # {3}          перетин (intersection)
print(set1 - set2)    # {1, 2}       різниця (difference)
print(set1 ^ set2)    # {1,2,4,5}    симетрична різниця
```

Приклад, який робить це не абстракцією — **два гуртки**:

```python
chess = {"Іваненко", "Петренко", "Коваль"}
robotics = {"Петренко", "Шевчук"}

print(chess & robotics)   # хто ходить на обидва
print(chess | robotics)   # усі, хто ходить хоч куди
print(chess - robotics)   # хто тільки на шахи
```

⚠ Один рядок замість вкладеного циклу. Це найкращий аргумент за множини, і саме
його варто показати.

Порядку в множині немає:

```python
print({3, 1, 2})    # може вивестись як {1, 2, 3} — але покладатись на це не можна
my_set[0]           # ⚠ TypeError: 'set' object is not subscriptable
```

### 4. Словники (14 хв, головна частина)

**Словник** — пари «ключ → значення». Найкорисніша структура в Python.

```python
student = {"name": "Аліса", "age": 15, "city": "Львів"}
```

Доступ за ключем:

```python
print(student["name"])       # Аліса
```

⚠ Ключа немає → `KeyError`. Тому надійніше:

```python
print(student.get("phone"))              # None, без помилки
print(student.get("phone", "не вказано"))  # значення за замовчуванням
```

🖥 Покажи обидва варіанти поспіль: `student["phone"]` падає, `student.get("phone")`
ні. Це прямий аналог `ISNULL` із дня 15 — і саме так варто це назвати.

Додати, змінити, видалити:

```python
student["email"] = "alice@example.com"    # додати
student["age"] = 16                       # змінити (той самий синтаксис!)
student.pop("city")                       # видалити й повернути
del student["age"]
```

⚠ Додавання й зміна виглядають однаково. Отже описка в ключі не дасть помилки —
вона тихо створить **новий** ключ. Це та сама категорія тихих помилок, що
`UPDATE` без `WHERE`.

Перебрати — три способи:

```python
for key in student.keys():
    print(key)

for value in student.values():
    print(value)

for key, value in student.items():       # найчастіший
    print(key, "=", value)
```

**Словник у словнику** — так зберігають те, для чого в базі була б таблиця:

```python
students = {
    1: {"name": "Аліса", "class": "9-А", "clubs": ["шахи"]},
    2: {"name": "Богдан", "class": "9-Б", "clubs": ["футбол", "шахи"]}
}

print(students[2]["name"])           # Богдан
print(students[2]["clubs"][0])       # футбол
```

⚠ **Зв'яжи це з днем 18.** Це буквально той самий документ JSON, який вони
писали для MongoDB. Словник Python і документ JSON — це одна й та сама
структура. Учні мусять це почути, бо на дні 26 і 29 воно знадобиться.

Що може бути ключем: **тільно незмінне** — рядок, число, кортеж. Список
ключем бути не може:

```python
d = {("Львів", "Стрийська"): "магазин"}   # кортеж ключем — можна
d = {["a", "b"]: 1}                        # ⚠ TypeError: unhashable type: 'list'
```

Ось і друга причина існування кортежів із розділу 2.

### 5. Як обирати (3 хв)

| Задача | Структура |
|---|---|
| Список учнів, який поповнюється | `list` |
| Координати точки, розмір екрана, дата | `tuple` |
| Прибрати дублікати, порівняти два набори | `set` |
| Знайти дані за ідентифікатором, «картка» об'єкта | `dict` |

Головне питання, яке треба задавати: **як я буду це шукати?** За номером —
список. За іменем чи ключем — словник. Не шукати, а порівнювати набори —
множина.

---

## ⚠ Що піде не так

| Симптом | Причина | Що робити |
|---|---|---|
| `TypeError: 'tuple' object does not support item assignment` | кортеж незмінний | так і має бути; треба список |
| `KeyError: 'phone'` | ключа немає | `get()` |
| Описка в ключі створила новий ключ | так працює присвоєння | перевіряти через `in` |
| `TypeError: 'set' object is not subscriptable` | у множині немає індексів | перебрати циклом або перетворити в список |
| `{}` виявився словником, а не множиною | так і є | порожня множина — `set()` |
| `TypeError: unhashable type: 'list'` | список як ключ словника | кортеж замість списку |

**Крок 5. Телефонна книга**

Підсумкове завдання: словник `ім'я → телефон`, меню з `while True`, дії
«додати», «знайти», «видалити», «показати всі», «вийти».

Що перевіряти:

- пошук через `get()`, а не через дужки
- перед видаленням перевірка `in`
- `while True` із `break` на виході

```python
phones = {}
while True:
    print("\n1-додати 2-знайти 3-видалити 4-усі 5-вийти")
    choice = input("Вибір: ")
    if choice == "1":
        name = input("Ім'я: ")
        phones[name] = input("Телефон: ")
    elif choice == "2":
        name = input("Ім'я: ")
        print(phones.get(name, "Немає такого контакту"))
    elif choice == "3":
        name = input("Ім'я: ")
        if name in phones:
            phones.pop(name)
        else:
            print("Немає такого контакту")
    elif choice == "4":
        for name, phone in phones.items():
            print(name, "—", phone)
    elif choice == "5":
        break
```

**Крок 6. Вибір структури**

Таблиця задач. Очікуване:

| Задача | Структура | Чому |
|---|---|---|
| Оцінки одного учня за семестр | `list` | порядок важливий, дублікати можливі |
| Координати на карті | `tuple` | не мусять змінюватись |
| Які мови знає учень | `set` | без дублікатів, порядок не важливий |
| Учень за номером у журналі | `dict` | доступ за ключем |
| Дні тижня | `tuple` | фіксований набір, ніколи не змінюється |
