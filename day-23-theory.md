## Виклад

### 1. Навіщо (6 хв)

Почни з болю. Напиши на дошці задачу: порахувати середнє для трьох різних
списків.

```python
total = 0
for n in list1:
    total += n
avg1 = total / len(list1)

total = 0
for n in list2:
    total += n
avg2 = total / len(list2)

# і ще раз те саме...
```

Питання класу: **що поганого?** Три відповіді, які треба витягнути:

1. код продубльований
2. знайшли помилку — правити треба в трьох місцях, і одне обов'язково забудуть
3. читати важко: за деталями не видно, що взагалі відбувається

**Функція** — це шматок коду з іменем, який можна викликати скільки завгодно
разів.

### 2. Оголошення та виклик (8 хв)

```python
def greetings():
    print("Привіт, світе!")

greetings()      # виклик
greetings()      # ще раз
```

Розбір по частинах:

- `def` — оголошуємо функцію
- `greetings` — ім'я (те саме правило `snake_case`, що для змінних)
- `()` — дужки, у них будуть аргументи
- `:` і **відступ** — тіло функції

⚠ **Оголошення не виконує код.** Функція виконається лише тоді, коли її
покличуть. Покажи це: запусти файл, у якому є тільки `def` без виклику —
нічого не станеться.

⚠ Функцію треба оголосити **вище** за виклик у файлі. Інакше `NameError`.

### 3. return проти print (10 хв — головна частина)

```python
def add_print(a, b):
    print(a + b)          # ПОКАЗУЄ на екрані

def add_return(a, b):
    return a + b          # ПОВЕРТАЄ значення в програму
```

Різниця стає видною, коли результат треба **використати далі**:

```python
x = add_print(5, 10)      # на екрані 15, але x дорівнює None
y = add_return(5, 10)     # на екрані нічого, але y дорівнює 15

print(y * 2)              # 30 — працює
print(x * 2)              # ⚠ TypeError
```

🖥 **Покажи це на проекторі повністю.** Аналогія, яка добре працює:

> `print` — це **сказати вголос**. `return` — це **віддати в руки**.
> Якщо ти сказав число вголос, порахувати з ним нічого не можна. Якщо віддав у
> руки — можна.

⚠ Функція без `return` повертає `None`. Це той самий `None`, що на дні 19, і та
сама пастка, що `numbers = numbers.sort()` на дні 21.

Ще дві властивості `return`:

```python
def check(n):
    if n > 0:
        return "додатне"
    return "недодатне"       # else не потрібен: return одразу виходить
```

`return` **негайно виходить із функції** — усе після нього не виконається.

Повертати можна кілька значень одразу — насправді це кортеж (день 22):

```python
def stats(numbers):
    return min(numbers), max(numbers), sum(numbers)

low, high, total = stats([3, 7, 1])
```

### 4. Аргументи (10 хв)

**Позиційні** — порядок важливий:

```python
def add(a, b):
    return a + b

print(add(5, 10))     # 15
```

**Іменовані** — порядок не важливий, зате зрозуміліше:

```python
def greetings(name, message):
    print(f"{message}, {name}!")

greetings(name="Анна", message="Привіт")
greetings(message="Привіт", name="Анна")     # те саме
```

⚠ Зв'яжи з днем 15: рівно так само викликались процедури SQL —
`EXEC ProductsByPrice @MinPrice = 100`. Учні це вже бачили.

**За замовчуванням:**

```python
def greetings(name, message="Привіт"):
    print(f"{message}, {name}!")

greetings("Анна")                      # Привіт, Анна!
greetings("Анна", "Доброго ранку")     # Доброго ранку, Анна!
```

⚠ Аргументи зі значенням за замовчуванням мусять стояти **після** звичайних.
Інакше `SyntaxError`.

**Змінна кількість:**

```python
def add(*args):
    result = 0
    for number in args:
        result += number
    return result

print(add(1, 2, 3, 4))      # 10

def print_data(**kwargs):
    for key, value in kwargs.items():
        print(f"{key}: {value}")

print_data(name="Анна", age=30)
```

`*args` збирає позиційні аргументи в кортеж, `**kwargs` — іменовані в словник.
⚠ Дай оглядово, одним прикладом кожен. Учні побачать це в чужому коді, писати
самі поки не мусять.

### 5. Локальні та глобальні змінні (8 хв)

```python
x = 10               # глобальна

def func():
    x = 5            # локальна — ІНША змінна з тим самим іменем
    print("Локальна x:", x)

func()               # 5
print("Глобальна x:", x)      # 10 — не змінилась
```

Правило: **змінна, створена всередині функції, живе тільки там** і зникає, коли
функція закінчується.

Читати глобальну змінну зсередини функції можна:

```python
counter = 0

def show():
    print(counter)      # працює
```

А змінити — ні:

```python
def increase():
    counter += 1        # ⚠ UnboundLocalError
```

Існує слово `global`, яке це дозволяє — **але скажи одразу, що ним майже не
користуються**. Правильний спосіб: передати значення аргументом і повернути
результат через `return`.

```python
def increase(counter):
    return counter + 1

counter = increase(counter)
```

Чому так краще: функція, яка залежить лише від своїх аргументів, **передбачувана
й перевіряється окремо**. Функція, яка лізе в глобальні змінні, ламається від
змін у іншому кінці програми.

### 6. lambda (3 хв)

Функція в один рядок і без імені:

```python
add = lambda a, b: a + b
print(add(5, 10))       # 15
```

Практично її вживають не так, а всередині інших функцій — наприклад для
сортування за складним ключем:

```python
students = [("Іваненко", 10), ("Петренко", 8)]
students.sort(key=lambda s: s[1])      # за оцінкою
```

⚠ Оглядово. Головне — щоб слово `lambda` в чужому коді не лякало.

---

## ⚠ Що піде не так

| Симптом | Причина | Що робити |
|---|---|---|
| Результат функції `None` | немає `return`, є `print` | розділ 3, аналогія «вголос / у руки» |
| `NameError: name 'func' is not defined` | виклик вище за оголошення | `def` перед викликом |
| Функція оголошена, але нічого не виводить | немає виклику | додати `func()` |
| `TypeError: func() missing 1 required positional argument` | забули аргумент | звірити з `def` |
| `UnboundLocalError` | змінюють глобальну змінну всередині функції | передати аргументом, повернути `return` |
| `SyntaxError: non-default argument follows default` | порядок аргументів | зі значенням за замовчуванням — у кінець |

**Крок 3. Функції з аргументами**

```python
def rectangle_area(width, height):
    return width * height

def is_even(n):
    return n % 2 == 0

def celsius_to_fahrenheit(c):
    return c * 9 / 5 + 32

def greet(name, greeting="Привіт"):
    return f"{greeting}, {name}!"
```

⚠ `is_even` мусить повертати `True`/`False`, а не текст «парне». Це вартісна
розмова: функція, що повертає булеве значення, вставляється прямо в `if`.

**Крок 4. Функції над списком** — головне завдання дня (воно й у назві лекції):

```python
def get_min(numbers):
    result = numbers[0]
    for n in numbers:
        if n < result:
            result = n
    return result

def get_average(numbers):
    return sum(numbers) / len(numbers)

def count_even(numbers):
    count = 0
    for n in numbers:
        if n % 2 == 0:
            count += 1
    return count

def above_average(numbers):
    avg = get_average(numbers)
    return [n for n in numbers if n > avg]
```

⚠ У `above_average` функція викликає іншу функцію. Це важливий момент: так
будується програма з частин. Хай учень зробить це саме так, а не копіює
обчислення середнього вдруге.

⚠ Порожній список зламає `get_min` і `get_average`. Питання «що буде, якщо
список порожній» — підводка до дня 26 (винятки). Не вимагай розв'язку, вимагай
помітити проблему.

**Крок 5. Локальні й глобальні** — експеримент із виклада плюс `UnboundLocalError`
і правильне виправлення через аргумент і `return`.

**Крок 6. Калькулятор із функцій** — підсумок: чотири функції (`add`,
`subtract`, `multiply`, `divide`) і меню в `while`.

⚠ У `divide` учень мусить сам додати перевірку на нуль. Зв'яжи з днем 15:
`NULLIF` робив те саме в SQL.
