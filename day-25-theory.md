### 1. Математичні функції (10 хв)

Вбудовані — імпортувати нічого не треба:

```python
print(abs(-7))              # 7
print(pow(2, 3))            # 8  — те саме, що 2 ** 3
print(round(3.14159, 2))    # 3.14
print(max([1, 5, 3]))       # 5
print(min([1, 5, 3]))       # 1
print(sum([1, 5, 3]))       # 9
```

⚠ Учні вже писали `min` і `max` циклом на дні 21 — і це було правильно, бо тоді
вчились. Скажи прямо: **у робочому коді пишуть готове**, а свою реалізацію
роблять лише для розуміння.

Одна тонкість `round`, яка здивує:

```python
print(round(2.5))     # 2, а не 3
print(round(3.5))     # 4
```

Python округлює **до найближчого парного** при рівній відстані. Це не помилка,
це стандарт для зменшення накопичення похибки. Достатньо знати, що так є.

**Модуль `math`** — те, чого немає вбудовано:

```python
import math

print(math.sqrt(16))          # 4.0
print(math.log(100, 10))      # 2.0
print(math.sin(math.pi / 2))  # 1.0
print(math.pi)                # 3.141592653589793
print(math.floor(3.7))        # 3  — вниз
print(math.ceil(3.2))         # 4  — вгору
```

⚠ `import math` — тепер уже свідомо. На дні 20 був `import random` без
пояснення; тут скажи, що модуль — це файл із готовим кодом, а детально буде на
дні 28.

⚠ `math.sqrt(16)` дає `4.0`, не `4` — результат завжди `float`.

### 2. Ітератори (10 хв)

**Ітератор** — об'єкт, який видає елементи по одному.

Учні цим користуються з дня 20, просто не знали назви:

```python
for fruit in ["яблуко", "банан"]:      # список
for char in "текст":                    # рядок
for key in {"a": 1, "b": 2}:            # словник — дає ключі
for num in (1, 2, 3):                    # кортеж
```

Що робить `for` насправді — покажи вручну:

```python
my_list = [10, 20, 30]
my_iter = iter(my_list)

print(next(my_iter))    # 10
print(next(my_iter))    # 20
print(next(my_iter))    # 30
print(next(my_iter))    # ⚠ StopIteration
```

**`for` — це те саме, тільки автоматично**, і він сам ловить `StopIteration`
і зупиняється.

🖥 Покажи `StopIteration` на проекторі. Це перше знайомство зі словом
«виняток» — назви його й скажи, що день 26 буде саме про це.

**Навіщо це знати.** Головна вигода — **пам'ять**:

```python
numbers = range(1_000_000)     # НЕ створює мільйон чисел у пам'яті
for n in numbers:
    ...                        # видає їх по одному
```

Якби `range` створював список, він з'їв би десятки мегабайтів. Ітератор
зберігає лише поточне число й правило, як отримати наступне.

Свій ітератор — **оглядово, не вимагати відтворення**:

```python
class MyIterator:
    def __init__(self, max):
        self.max = max
        self.current = 0

    def __iter__(self):
        return self

    def __next__(self):
        if self.current < self.max:
            self.current += 1
            return self.current
        raise StopIteration


for num in MyIterator(5):
    print(num)          # 1 2 3 4 5
```

⚠ Зв'яжи з днем 24: `__iter__` і `__next__` — такі самі спеціальні методи, як
`__init__` і `__str__`. Python домовився про імена з підкресленнями, і за ними
впізнає, що об'єкт уміє робити.

### 3. Методи рядків (16 хв — головна частина)

Повторення з дня 19 — швидко:

```python
text = "Python"
print(text[0], text[-1])     # P n
print(text[0:2])             # Py
print(text[2:])              # thon
print(len(text))             # 6
print("Hi! " * 3)
print("John" + " " + "Doe")
```

Тепер нове. Показуй кожен метод із результатом:

```python
text = "Python Is Fun!"

print(text.lower())          # python is fun!
print(text.upper())          # PYTHON IS FUN!
print(text.title())          # Python Is Fun!
print(text.count("n"))       # 2
print(text.find("Is"))       # 7  — індекс, або -1 якщо немає
print(text.startswith("Py")) # True
print(text.endswith("!"))    # True
```

**`strip()`** — прибирає пробіли з країв:

```python
text = "   Привіт   "
print(text.strip())          # "Привіт"
print(text.lstrip())         # тільки злива
print(text.rstrip())         # тільки справа
```

⚠ Найпрактичніше застосування, яке варто назвати: `input().strip()`.
Користувач майже завжди залишить зайвий пробіл, і без `strip` порівняння
`if answer == "так"` не спрацює.

**`split()` і `join()`** — пара, яку варто розібрати разом:

```python
sentence = "Python is awesome"
words = sentence.split()             # ['Python', 'is', 'awesome']

data = "Іваненко;9-А;10"
parts = data.split(";")              # ['Іваненко', '9-А', '10']

back = " ".join(words)               # "Python is awesome"
csv_line = ";".join(parts)           # "Іваненко;9-А;10"
```

⚠ Синтаксис `join` збиває з пантелику: **роздільник ліворуч**, список у дужках.
Не `words.join(" ")`, а `" ".join(words)`. Покажи обидва варіанти й помилку.

Скажи, що `split(";")` — це те, як читають CSV-файли, і на дні 26 воно
знадобиться для читання з файлу.

**`replace()`:**

```python
text = "I like Python"
print(text.replace("like", "love"))     # I love Python
```

⚠ Рядки **незмінні** (день 21). Тому `replace` **повертає новий рядок**, а
оригінал не чіпає:

```python
text.replace("like", "love")     # результат втрачено!
text = text.replace("like", "love")   # правильно
```

Це та сама пастка, що `numbers.sort()` на дні 21, тільки навпаки: там метод
змінював і нічого не повертав, тут — повертає й не змінює.

### 4. Форматування рядків (7 хв)

Три способи, історично:

```python
name, age = "Аліса", 25

text1 = "Мене звати %s, мені %d років" % (name, age)      # старий
text2 = "Мене звати {} , мені {} років".format(name, age)  # середній
text3 = f"Мене звати {name}, мені {age} років"             # ⭐ сучасний
```

⚠ Скажи прямо: **пиши f-рядки**. Решту треба впізнавати в чужому коді, писати
самому — ні.

Що вміють f-рядки, крім підстановки:

```python
price = 1234.5678
print(f"Ціна: {price:.2f}")            # Ціна: 1234.57
print(f"{2 + 2 * 2}")                  # 6 — можна вирази
print(f"Ім'я: {name.upper()}")         # виклик методу
print(f"{'текст':>10}")                # вирівнювання справа
```

`:.2f` — два знаки після коми. Це знадобиться скрізь, де є гроші й середні
значення.

## ⚠ Що піде не так

| Симптом | Причина | Що робити |
|---|---|---|
| `AttributeError: 'list' object has no attribute 'join'` | `words.join(" ")` | навпаки: `" ".join(words)` |
| `replace` «не працює» | результат не збережено | `text = text.replace(...)` |
| `math` не знайдено | забули `import math` | імпорт на початку файлу |
| `round(2.5)` дає 2 | округлення до парного | так і має бути |
| Порівняння рядків не спрацьовує | зайві пробіли або регістр | `.strip()` і `.lower()` |
| `StopIteration` | ітератор вичерпано | так і має бути; `for` це ловить сам |
| `find` повернув `-1` | підрядка немає | перевіряти через `in` |
