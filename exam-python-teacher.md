## Частина 2. Функції (20 хв)

Мінімум **чотири** функції, кожна з `return`.

Що перевіряти:

| Ознака | Чому важлива |
|---|---|
| функція **повертає**, а не друкує | день 23, головна ідея |

# Урок 2: збереження й підсумки

## Частина 4. Файли (20 хв)

```python
def save_to_file(items, filename):
    with open(filename, "w", encoding="utf-8") as f:
        for item in items:
            f.write(f"{item['id']};{item['title']};{item['author']}\n")


def load_from_file(filename):
    items = []
    try:
        with open(filename, "r", encoding="utf-8") as f:
            for line in f:
                parts = line.strip().split(";")
                items.append({"id": int(parts[0]), "title": parts[1], "author": parts[2]})
    except FileNotFoundError:
        print("Файл не знайдено, починаємо з порожнього списку")
    return items
```

Що перевіряти:

- ✅ `with open(...)` і **`encoding="utf-8"`**
- ✅ `FileNotFoundError` обробляється — програма при першому запуску не падає
- ✅ `int()` при читанні числових полів
- ✅ `.strip()` перед `.split()`
- ⚠ **Головна перевірка:** запустити програму, додати дані, **закрити**,
  запустити знову. Дані на місці?
