## Наскрізні зв'язки між блоками

Ці зшивки закладені в матеріал навмисно — вони помітно допомагають:

| Із блоку баз даних | У блоці Python |
|---|---|
| `SELECT DISTINCT` (день 7) | `set` (день 22) |
| `ISNULL` (день 15) | `dict.get()` (день 22) |
| `DECIMAL` для грошей (день 8) | чому `0.1 + 0.2 ≠ 0.3` (день 19) |
| JSON-документ (день 18) | словник у словнику (день 22) |
| `CHECK` і процедури (дні 9, 15) | інкапсуляція (день 24) |
| індекси, `Index Seek` (день 10) | бінарний пошук, O(log n) (день 27) |
| тимчасові таблиці (день 14) | мемоізація Фібоначчі (день 27) |
| `TRY … CATCH` (день 16) | `try` / `except` (день 26) |
| `COMMIT TRANSACTION` (день 16) | `conn.commit()` (день 29) |
