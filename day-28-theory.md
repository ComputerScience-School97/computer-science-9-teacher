## Виклад

### 1. Модулі та імпорт (6 хв)

**Модуль — це файл із кодом Python.** Оце й усе визначення. Учні вже
користувались модулями: `random` на дні 20, `math` на дні 25, `sys` на дні 25.

Три способи підключити:

```python
# 1. увесь модуль
import math
print(math.sqrt(16))

# 2. окремі назви з модуля
from math import sqrt, pi
print(sqrt(25))          # без префікса

# 3. під коротким іменем
import math as m
print(m.pi)
```

Коли який доречний:

| Спосіб | Коли |
|---|---|
| `import math` | ⭐ за замовчуванням. Видно, звідки функція |
| `from math import sqrt` | коли з модуля потрібні одна-дві речі |
| `import math as m` | коли ім'я довге (`import pandas as pd`) |

⚠ Чому третій спосіб гірший за перший: у коді `sqrt(25)` **не видно**, звідки
взялась ця функція. У великому файлі з десятком імпортів це стає проблемою.

⚠ І окремо: `from math import *` — так **не пишуть**. Це затягує всі назви з
модуля й може непомітно перекрити твої власні змінні.

### 2. Власний модуль (8 хв — найважливіше для розуміння)

Тут головна думка дня: **модуль — це не щось особливе. Це просто твій файл.**

Створюємо `geometry.py`:

```python
def rectangle_area(a, b):
    return a * b

def circle_area(r):
    import math
    return math.pi * r ** 2
```

Використовуємо з `main.py` **у тій самій папці**:

```python
import geometry

print(geometry.rectangle_area(4, 7))     # 28
print(geometry.circle_area(5))
```

⚠ Умова: обидва файли в одній папці. Інакше `ModuleNotFoundError`.

🖥 Зроби це живцем на проекторі. Момент, коли учні бачать, що `import geometry`
працює так само, як `import math`, — і є ціль розділу.

**`if __name__ == "__main__"`** — варто дати, бо в лекції це є в коді дня 29:

```python
# geometry.py
def rectangle_area(a, b):
    return a * b

if __name__ == "__main__":
    # виконається ТІЛЬКИ якщо запустити цей файл напряму
    print("Перевірка:", rectangle_area(2, 3))
```

Сенс: коли файл імпортують, ця частина не виконується. Так у модуль можна
покласти власну перевірку, і вона не спрацює в чужій програмі.

⚠ Не заглиблюйся в те, що таке `__name__`. Достатньо правила: **код під цим
рядком виконується лише при прямому запуску файлу.**

### 3. datetime (16 хв — головна частина)

```python
import datetime

now = datetime.datetime.now()
print(now)                    # 2026-09-03 14:32:17.123456
print(now.date())             # 2026-09-03
print(now.time())             # 14:32:17.123456
print(now.year, now.month, now.day)
```

Зручніший імпорт, який варто одразу дати:

```python
from datetime import date, datetime, timedelta

today = date.today()
print(today)
```

**Конкретна дата:**

```python
birthday = date(2010, 5, 15)      # рік, місяць, день — у цьому порядку
```

**Різниця між датами** — тут головна практична сила модуля:

```python
today = date.today()
birthday = date(2010, 5, 15)
delta = today - birthday
print("Днів прожито:", delta.days)
```

⚠ Різниця двох дат дає не число, а об'єкт `timedelta`. Число днів — у
`.days`. Учні спробують вивести `delta` напряму й побачать щось на кшталт
`5955 days, 0:00:00`.

**Додати до дати:**

```python
from datetime import timedelta

future = today + timedelta(days=30)
week_ago = today - timedelta(weeks=1)
```

⚠ `timedelta` вміє `days`, `weeks`, `hours`, `minutes`, `seconds` — але **не
`months` і не `years`**. Питання класу: **чому?** Бо «місяць» — не фіксована
кількість днів. Це гарний приклад того, що дати складніші, ніж здається.

**Форматування** через `strftime`:

```python
print(today.strftime("%d.%m.%Y"))      # 03.09.2026
print(today.strftime("%A"))            # день тижня англійською
print(today.strftime("%d %B %Y"))
```

Головні позначки — виписати на дошку:

| Код | Що дає |
|---|---|
| `%d` | день |
| `%m` | місяць числом |
| `%Y` | рік чотирма цифрами |
| `%H:%M` | години й хвилини |
| `%A` | день тижня словом |
| `%B` | місяць словом |

**Зворотна операція** — розібрати дату з рядка:

```python
from datetime import datetime
d = datetime.strptime("15.05.2010", "%d.%m.%Y").date()
```

⚠ Це знадобиться на практиці: у файлі з дня 26 дати лежали текстом. Тепер їх
можна перетворити в справжні дати й порівнювати. Скажи це вголос — зв'язок
корисний.

Приклад із лекції, який варто зробити на проекторі:

```python
today = date.today()
new_year = date(today.year + 1, 1, 1)
print("Днів до Нового року:", (new_year - today).days)
```

### 4. PIP (10 хв)

**`pip`** — менеджер пакетів. Ставить бібліотеки, яких немає в Python із
коробки.

Різниця, яку треба чітко провести:

| | Стандартна бібліотека | Сторонній пакет |
|---|---|---|
| Приклади | `math`, `random`, `datetime`, `os`, `json` | `requests`, `pandas`, `numpy`, `pyodbc` |
| Установка | не потрібна | `pip install` |
| Хто написав | розробники Python | хто завгодно |

```
pip install requests
pip install emoji
pip list
pip uninstall emoji
```

⚠ Якщо `pip` не знайдено, спробувати `python -m pip install requests`. Це
надійніший варіант, бо не залежить від `PATH`.

```python
import requests
response = requests.get("https://www.python.org")
print("Код відповіді:", response.status_code)     # 200 = все добре
```

**Скажи про безпеку** — це важливіше за синтаксис. `pip` ставить код із
інтернету, який написала невідома людина, і цей код отримує ті самі права, що
твоя програма. Правила:

1. Дивись на кількість завантажень і дату останнього оновлення.
2. Перевіряй **назву по літерах** — бувають пакети з іменами, схожими на
   популярні, з одруківкою в один символ. Це відома атака.
3. Не встановлюй пакет, який тобі порадив невідомий сайт.

⚠ Зв'яжи з днем 3 (інформаційна безпека) і днем 2 (ліцензії): у кожного пакета
є ліцензія, і `pip install` — це прийняття її умов.

## ⚠ Що піде не так

| Симптом | Причина | Що робити |
|---|---|---|
| `ModuleNotFoundError: No module named 'geometry'` | свій модуль в іншій папці | обидва файли в одну папку |
| `ModuleNotFoundError: No module named 'requests'` | пакет не встановлено | `pip install requests` |
| `pip` не знайдено | немає в `PATH` | `python -m pip install ...` |
| `pip` не працює через мережу | школа блокує PyPI | резервний варіант практики без сторонніх пакетів |
| `TypeError: unsupported type for timedelta days` | `timedelta(months=1)` | місяців немає, лише дні й тижні |
| `delta` виводиться дивно | це об'єкт, не число | `.days` |
| Свій файл назвали `math.py` | перекрив стандартний модуль | ⚠ ніколи не називай файл як модуль |
