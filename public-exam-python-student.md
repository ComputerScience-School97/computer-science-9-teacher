## Частина 2. Функції (20 хв)

Напиши **щонайменше чотири** функції.

⚠ **Три обов'язкові вимоги до кожної:**

1. Дані отримує **аргументом**, а не бере з глобальної змінної.
2. Результат **повертає через `return`**, а не друкує.
3. Робить **одну** справу.

Приклади того, які функції потрібні (адаптуй під свій варіант):

| Функція | Що повертає |
|---|---|
| `find_by_id(items, item_id)` | знайдений об'єкт або `None` |
| `get_available(books)` | список вільних книг |
| `give_book(books, book_id, reader_id)` | `True`/`False` — вдалось чи ні |
| `count_by_type(items)` | словник «вид → кількість» |

⚠ **Не роби так:**

```python
def show_books():                 # ⚠ бере books звідкись зовні
    for b in books:               # ⚠ і друкує замість повертати
        print(b["title"])
```

**Роби так:**

```python
def get_available(books):
    return [b for b in books if b["taken_by"] is None]

# друкує вже той, хто викликав
for b in get_available(books):
    print(b["title"])
```

⚠ Щонайменше **одна** функція мусить викликати **іншу** твою функцію.

## Частина 6 (для 11–12 балів). Класи або база

Зроби **одне** з двох на вибір.

### Варіант «класи» (день 24)

Перепиши головну сутність класом:

```python
class Book:
    def __init__(self, book_id, title, author, year):
        self.id = book_id
        self.title = title
        self.author = author
        self.year = year
        self.taken_by = None

    def is_available(self):
        return self.taken_by is None

    def __str__(self):
        status = "вільна" if self.is_available() else f"у читача {self.taken_by}"
        return f"{self.id}. {self.title} — {self.author} ({status})"
```

### Варіант «база» (день 29)

Замість файлу зберігай дані в **SQLite** або в **SQL Server**:

```python
import sqlite3

conn = sqlite3.connect("library.db")
cursor = conn.cursor()

cursor.execute("""
    CREATE TABLE IF NOT EXISTS Books (
        ID INTEGER PRIMARY KEY,
        Title TEXT NOT NULL,
        Author TEXT,
        TakenBy INTEGER
    )
""")

cursor.execute("INSERT INTO Books VALUES (?, ?, ?, ?)", (1, "Кобзар", "Шевченко", None))
conn.commit()
```

⚠ Значення — **тільки через `?`**. І не забудь `commit()`.
