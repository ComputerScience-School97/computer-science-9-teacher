## Виклад

### 1. Що таке виняток (5 хв)

Почни зі списку помилок, які клас уже зібрав за сім днів:

| Помилка | Де трапилась |
|---|---|
| `ValueError` | `int("привіт")` — день 19 |
| `IndexError` | `text[13]` — день 19 |
| `ZeroDivisionError` | `100 / 0` — день 15 (у SQL) і день 23 |
| `KeyError` | ключ, якого немає в словнику — день 22 |
| `TypeError` | `age + 1`, де `age` це текст — день 19 |
| `StopIteration` | `next()` після кінця — день 25 |

**Виняток** — подія, яка порушує нормальний перебіг програми. Досі кожна з них
означала одне: **програма впала**.

Питання класу: **що станеться з калькулятором із дня 23, якщо користувач введе
`нуль` замість числа?** Програма закриється, і всі попередні обчислення
загубляться. Ось це ми й виправляємо.

### 2. try / except (13 хв — головна частина)

```python
try:
    x = 10 / 0
except ZeroDivisionError:
    print("Ділення на нуль неможливе!")
```

Механіка: Python виконує блок `try`. Якщо все добре — `except` пропускається.
Якщо трапився виняток указаного типу — виконується `except`, і **програма
живе далі**.

🖥 Покажи на проекторі різницю: спершу код без `try`, який падає й далі нічого не
виконує, потім із `try`, де після обробки виводиться ще один рядок.

**Кілька `except` для різних помилок:**

```python
try:
    number = int(input("Число: "))
    result = 100 / number
    print(result)
except ValueError:
    print("Це не число!")
except ZeroDivisionError:
    print("На нуль ділити не можна!")
```

⚠ **Важливе правило: вказуй конкретний тип помилки.** Можна написати просто
`except:` без типу, і воно зловить усе — але це погана практика:

```python
try:
    ...
except:            # ⚠ так не пишуть
    print("Щось не так")
```

Чому погано: така конструкція проглине **будь-яку** помилку, зокрема твою
власну описку в коді. Програма не впаде, але й працювати правильно не буде, а
ти не дізнаєшся, чому.

**Текст помилки можна отримати:**

```python
try:
    number = int("привіт")
except ValueError as e:
    print("Помилка:", e)      # invalid literal for int() with base 10: 'привіт'
```

### 3. else, finally, свої винятки (6 хв)

```python
try:
    x = 5 / 1
except ZeroDivisionError:
    print("Ділення на нуль!")
else:
    print("Виконалось успішно")     # якщо винятку НЕ було
finally:
    print("Це виконається завжди")  # і при помилці, і без неї
```

`finally` потрібен для прибирання: закрити файл, закрити з'єднання з базою.

⚠ Зв'яжи з днем 16: `TRY … CATCH` у SQL Server — це рівно те саме, і там у
`CATCH` ми робили `ROLLBACK`. Одна ідея, дві мови.

**Свій виняток** — оглядово:

```python
class TooYoungError(Exception):
    pass

age = 10
try:
    if age < 14:
        raise TooYoungError("Замалий вік для реєстрації")
except TooYoungError as e:
    print(e)
```

`raise` створює виняток самостійно. ⚠ Зв'яжи з днем 24: свій виняток — це
**клас, успадкований від `Exception`**. Наслідування вже знайоме.

### 4. Надійний ввід (8 хв)

Просто:

```python
age = int(input("Вік: "))       # ⚠ впаде на будь-якому нечисловому вводі
```

Із обробкою:

```python
try:
    age = int(input("Вік: "))
    print(f"Через рік буде {age + 1}")
except ValueError:
    print("Введіть число!")
```

Але цього мало: програма попередила й закінчилась. **Правильний шаблон —
цикл, поки не введуть правильно:**

```python
while True:
    try:
        age = int(input("Вік: "))
        break                      # вийшли, бо все добре
    except ValueError:
        print("Це не число, спробуй ще раз")

print(f"Через рік буде {age + 1}")
```

⚠ **Це найкорисніший шаблон дня.** Він знадобиться в кожній програмі з
введенням, тому варто дати його під запис і повторити словами: `while True` +
`try` + `break` у кінці успішної спроби.

Перевірка не лише типу, а й значення:

```python
while True:
    try:
        age = int(input("Вік (1-120): "))
        if 1 <= age <= 120:
            break
        print("Вік мусить бути від 1 до 120")
    except ValueError:
        print("Це не число")
```

### 5. Файли (11 хв)

Старий спосіб — і одразу скажи, що так не пишуть:

```python
file = open("example.txt", "r")
content = file.read()
file.close()          # ⚠ забув — файл лишився відкритим
```

**Правильний спосіб — `with`:**

```python
with open("example.txt", "r", encoding="utf-8") as file:
    content = file.read()
    print(content)
# файл закритий автоматично, навіть якщо сталася помилка
```

⚠⚠ **`encoding="utf-8"` обов'язково.** Без нього український текст на Windows
або зламається, або дасть `UnicodeDecodeError`. Це та сама тема, що `NVARCHAR`
на дні 8 — і скажи це вголос, зв'язок точний.

**Режими:**

| Режим | Що робить |
|---|---|
| `"r"` | читати (за замовчуванням); файлу немає → `FileNotFoundError` |
| `"w"` | писати — **⚠ стирає весь наявний вміст** |
| `"a"` | дописувати в кінець |
| `"rb"` / `"wb"` | бінарний режим (картинки, відео) |

⚠ Різницю `"w"` і `"a"` покажи обов'язково: запусти програму із `"w"` двічі й
покажи, що файл не виріс. Учні на цьому втратять свої дані на практиці, якщо не
попередити.

**Читання — три способи:**

```python
with open("data.txt", "r", encoding="utf-8") as f:
    content = f.read()            # усе одним рядком

with open("data.txt", "r", encoding="utf-8") as f:
    lines = f.readlines()         # список рядків

with open("data.txt", "r", encoding="utf-8") as f:
    for line in f:                # ⭐ найкращий спосіб — построчно
        print(line.strip())
```

Третій варіант — найкращий: файл на гігабайт не влізе в пам'ять цілком, а
построчно прочитається. ⚠ Це рівно та сама ідея, що ітератори на дні 25.

`line.strip()` потрібен, бо кожен рядок приходить із символом переносу в кінці.

**Запис:**

```python
with open("output.txt", "w", encoding="utf-8") as f:
    f.write("Перший рядок\n")
    f.write("Другий рядок\n")

lines = ["один\n", "два\n", "три\n"]
with open("output.txt", "w", encoding="utf-8") as f:
    f.writelines(lines)
```

⚠ `write` **не додає** перенос рядка сам — `\n` пишемо вручну. `writelines`
теж не додає.

**Файли й винятки разом** — те, для чого весь урок і побудований у такому
порядку:

```python
try:
    with open("nonexistent.txt", "r", encoding="utf-8") as f:
        content = f.read()
except FileNotFoundError:
    print("Файл не знайдено!")
except PermissionError:
    print("Немає прав на читання файлу")
```

---

## ⚠ Що піде не так

| Симптом | Причина | Що робити |
|---|---|---|
| `FileNotFoundError` | файл не там, де програма | покласти файл у ту саму папку, що `.py`; або обробити виняток |
| `UnicodeDecodeError` | немає `encoding="utf-8"` | додати |
| Українські літери «кракозябрами» | те саме | те саме |
| Файл спорожнів | відкрили в `"w"` замість `"a"` | попередити **до** практики |
| `except:` без типу проглинає описки | занадто широка обробка | завжди конкретний тип |
| Нескінченний цикл введення | `break` не в тому місці | `break` одразу після успішного `int(...)` |
| Рядки з файлу з зайвими переносами | символ `\n` у кінці | `.strip()` |

**Крок 5. Читання й обробка**

```python
students = []
try:
    with open("students.txt", "r", encoding="utf-8") as f:
        for line in f:
            parts = line.strip().split(";")

                "class": parts[1],
                "grade": int(parts[2])

except FileNotFoundError:

```
